# Product Cards UI

A simple and responsive product card interface built with **HTML**, **Tailwind CSS**, and **Vite**.

This project demonstrates how to create reusable-looking product cards with modern UI styling, responsive layouts, and clean design principles.

## ✨ Features

- Responsive product card layout
- Mobile-first design
- Three different product cards:
  - Premium Yoga Mat
  - Sports Water Bottle
  - Adjustable Dumbbells

- Hover animations
- Product image display
- Price and rating sections
- Responsive layout for mobile, tablet, and desktop screens

## 🛠 Technologies

- HTML5
- Tailwind CSS
- Vite
- JavaScript

## 🚀 Getting Started

### 1. Clone the project

```bash
git clone <repository-url>
```

### 2. Navigate to the project folder

```bash
cd hello-part
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

The project will start on a local development server.

## 📱 Responsive Behavior

The layout adapts based on screen size:

- **Mobile:** Cards are displayed vertically.
- **Tablet:** Cards adjust based on available space.
- **Desktop:** Cards are displayed in a row with proper spacing.

## 🎨 UI Details

Each product card includes:

- Product image
- Product title
- Category label
- Description
- Price
- Rating
- Action buttons

The cards use Tailwind CSS utility classes for:

- Layout management
- Spacing
- Colors
- Shadows
- Hover animations
- Responsive breakpoints
